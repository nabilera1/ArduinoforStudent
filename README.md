## 구성

기초 1장, 센서·출력 실습 24장, Python 기록 1장, 실생활 프로젝트 4장으로 구성했습니다. 각 장에는 이미지, 핵심 설명, 코드, 퀴즈, 프로그래밍 문제, 활동지, 정답과 PPT 링크가 있습니다. 30차시로 운영하며 센서별 수업 뒤 실생활 문제해결 프로젝트를 진행합니다.

## 실행

Arduino IDE에서 code 안의 해당 이름 폴더와 .ino 파일을 열어 업로드합니다. PC Python은 `py -m pip install -r requirements.txt` 실행 후 해당 read_sensor.py를 `--port COM3` 옵션과 함께 실행합니다. COM3은 실제 포트로 바꿉니다.
