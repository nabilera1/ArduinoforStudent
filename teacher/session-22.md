## 22차시 조이스틱 교사 해설

### 학습 초점

두 축과 버튼. 두 가변저항으로 X/Y 위치를 읽고 버튼도 확인합니다.

### 퀴즈와 설명

1. 부품 오차 때문에 다르므로 실제 중앙값을 기록해야 합니다.
2. 프로그램이 읽는 가로와 세로 방향이 바뀝니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

X 출력 방향을 반대로 바꾸세요.

[정답과 상세 해설](../answers/20_joystick.md)

### 평가 근거와 피드백

출력 열: X,Y,버튼. 중앙값은 정확히 512가 아닐 수 있습니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
