## 30차시 생활 문제 해결과 검증 교사 해설

### 학습 초점

재현 가능한 시험과 개선. 문제를 정의하고 정상·경계·오류 조건으로 작품을 검증합니다.

### 퀴즈와 설명

1. 정상·경계·오류 조건을 반복해 확인해야 합니다.
2. 모델, 회로, 코드, 조건과 결과를 남깁니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

켜짐 300, 꺼짐 700의 자동 조명 상태를 예측하세요.

[정답과 상세 해설](../answers/29_design.md)

### 평가 근거와 피드백

한 번 작동한 결과보다 반복 가능한 근거가 중요합니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
