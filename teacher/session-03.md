## 03차시 가변저항과 LED 교사 해설

### 학습 초점

전압 분배와 PWM. 전압 분배로 만든 입력값을 PWM 밝기로 바꿉니다.

### 퀴즈와 설명

1. 기준 전압 5V에서 약 2.5V입니다.
2. 안 됩니다. 저항이 LED와 핀에 흐르는 전류를 제한합니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

최대 PWM 값을 128로 제한하세요.

[정답과 상세 해설](../answers/01_pot.md)

### 평가 근거와 피드백

LED 긴 다리는 보통 양극입니다. PWM은 켜짐 시간 비율입니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
