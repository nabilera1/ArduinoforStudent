## 02차시 Python 데이터 기록 교사 해설

### 학습 초점

문자열에서 유효한 숫자로. 열 수와 오류값을 확인한 뒤 CSV로 기록합니다.

### 퀴즈와 설명

1. 문자열의 결합과 숫자 계산은 다르므로 float 변환으로 계산할 수 있게 합니다.
2. NaN은 float 변환에 성공하지만 유효한 측정값이 아닙니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

유효한 raw 값의 평균을 계산하세요.

[정답과 상세 해설](../answers/25_python.md)

### 평가 근거와 피드백

NaN은 숫자 변환에 성공하므로 유한값 검사도 필요합니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
