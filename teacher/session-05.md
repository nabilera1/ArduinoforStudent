## 05차시 버튼 교사 해설

### 학습 초점

풀업과 논리 반전. 누르면 접점이 연결됩니다.

### 퀴즈와 설명

1. GND와 연결되므로 LOW입니다.
2. 내부 풀업 저항이 입력을 HIGH로 유지합니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

누른 상태가 유지되는 동안 내장 LED를 켜세요.

[정답과 상세 해설](../answers/03_button.md)

### 평가 근거와 피드백

모듈이 아닌 2단자 접점 기준. 접점이 닫히면 출력 1입니다. 버튼의 같은 쪽 두 다리는 이미 연결되어 있을 수 있습니다. 접점 튐 때문에 빠른 계수에는 디바운싱이 필요합니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
