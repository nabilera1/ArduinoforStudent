## 25차시 RGB LED 교사 해설

### 학습 초점

빛의 색 혼합. 세 색의 PWM을 혼합합니다.

### 퀴즈와 설명

1. 각 색의 전류가 영향을 받으므로 색마다 저항을 사용합니다.
2. 아닙니다. 공통 단자 연결과 PWM 논리를 바꿔야 합니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

초록색만 켜세요.

[정답과 상세 해설](../answers/23_rgb.md)

### 평가 근거와 피드백

공통 음극형 기준이며 각 색마다 저항이 하나씩 필요합니다. 다리 배열을 확인하세요. 공통 양극형은 배선과 PWM 값이 달라집니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
