## 27차시 작은 자동 조명 교사 해설

### 학습 초점

히스테리시스. 켜짐 기준과 꺼짐 기준을 다르게 설정합니다.

### 퀴즈와 설명

1. 경계에서 작은 입력 변화 때문에 출력이 반복해서 바뀌는 일을 줄입니다.
2. 600 초과가 아니므로 켜짐 상태를 유지합니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

켜짐 300, 꺼짐 700에서 상태 변화를 예측하세요.

[정답과 상세 해설](../answers/26_project.md)

### 평가 근거와 피드백

경계 안에서는 이전 상태를 유지합니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
