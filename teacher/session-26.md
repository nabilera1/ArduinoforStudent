## 26차시 pH 센서 SEN0161-V2 교사 해설

### 학습 초점

표준액과 두 점 보정. 전극 신호를 변환 보드로 읽고 표준 완충액으로 보정합니다.

### 퀴즈와 설명

1. 전극의 전압과 pH 관계에서 기울기와 기준점을 맞추기 위해서입니다.
2. 제조사 지정 전극 보관액을 사용합니다.
3. 실제 코드를 근거로 입력·조건·출력이 연결되는 설명을 인정합니다. 오류값을 정상값처럼 해석하면 다시 지도합니다.

### 프로그래밍 문제

온도 가정값을 실제 측정한 23°C로 바꾸세요.

[정답과 상세 해설](../answers/24_ph.md)

### 평가 근거와 피드백

SEN0161-V2 전용. 시리얼 모니터 9600 baud에서 pH 7과 4 표준액으로 각각 안정화 후 enterph → calph → exitph를 전송해 성공/저장 메시지를 확인합니다. Python 실행 전 보정을 마치세요. 전극을 헹군 뒤 시료를 재고 제조사 지정 보관액에 보관합니다. 25°C는 가정값이며 실제 온도로 수정하세요. 보드와 BNC는 건조하게 유지합니다.

[공통 루브릭](rubric.md)을 사용하여 핀 연결·코드 설명·시험 근거를 관찰합니다. 중학생은 한 줄 수정과 상태 설명, 고등학생은 오류 처리와 자료 분석까지 확장합니다. 모의 데이터와 실측 데이터를 구분해 제출하게 합니다.
